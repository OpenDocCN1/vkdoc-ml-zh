# 引言

数据工程的角色已变得日益关键。数据工程是组织构建其报告、分析和机器学习能力的基础。作为一门学科，数据工程将原始数据转化为可靠且富有洞察力的信息资源，为组织提供宝贵见解。然而，数据工程远不止于此。它是一个复杂且迭代的过程。

如果将一个企业项目比作建造一栋多层建筑，那么数据工程就是执行发生的地方——从架构设计和规划数据解决方案的结构，到铺设数据存储基础；安装数据处理框架；开发用于数据源、整理、转换和集成的管道；以及开发报告和仪表板，同时确保系统、管道、报告和仪表板的质量和维护，以及其他诸多事项。

本书旨在作为您的案头参考。无论您是初学者还是专业人士，本书都将帮助您掌握基础知识，并提供即用技能，为企业交付高价值主张。本书的写作目标是回归传统教科书学习所获得的知识，提供对关键数据工程概念和实践的有组织探索。我鼓励您拥有一本纸质版。在概念、工具和实践方面，本书将在未来十年为您提供良好服务。

尽管内容详尽，本书仅涵盖了约 60%的数据工程主题。数据工程是一门复杂且不断发展的学科；还有更多主题未被涉及。作为读者，我鼓励您联系我，分享您的见解以及您在数据领域希望分享的见闻。我感谢那些已经给我写信的人，并希望看到读者和爱好者们更多的此类努力。

话虽如此，本书涵盖了现代数据工程实践中广泛的主题，重点聚焦于为机器学习开发构建数据管道。本书按以下主题组织：

*   数据整理：使用 `Pandas`、`Polars` 和基于 GPU 的 `CuDF` 库进行数据清洗、转换和准备分析的技术
*   数据验证：使用 `Pydantic`、`Pandera` 和 `Great Expectations` 确保整个管道中的数据质量和完整性
*   并发计算：利用 `Dask` 和 `DaskML` 进行并行处理以提升性能
*   API：使用 `FastAPI` 设计和处理用于数据交换的 API
*   流式管道：使用 `Kafka` 高效设计和处理实时数据流
*   工作流编排：使用 `cron`、`Airflow` 和 `Prefect` 管理复杂的数据工作流和依赖关系
*   云计算：利用 `AWS`、`Azure` 和谷歌云平台（`GCP`）的云服务实现可扩展的数据工程解决方案

本书涵盖了主要的云计算服务提供商。原因是组织正日益转向多云方法。因此，掌握多样化云环境的知识对您的职业成功至关重要。本书将为您提供这一点。

如果您是一位希望扩展技能并向上晋升的数据工程师，一位想了解底层工作原理的数据科学家，一位已经在从事相关工作的软件工程师，或者一位希望获得职位的学生，本书对您来说都是必不可少的。即使您身处职能领域或是一家初创公司的创始人，对组建团队和良好数据工程实践感兴趣，本书也将从头到尾为您提供帮助。本书是一本指南，将帮助处于每个阶段（从新手到专家）的人学习。

我强烈建议您在学习期间不要向聊天机器人寻求解决方案。在撰写本书时（2024 年 6 月），许多机器人程序要么提供遗留代码，要么将您引向它们自己的方向和方法。由于信息呈现的方式，这看起来可能更好，但实际上会减慢您的学习和专业发展。即使到今天，我仍然发现搜索引擎更有效，它们会将我带至问答网站，在那里可以看到解决方案是如何得出的，以及为什么其他方法没有成功。此外，我发现谷歌搜索在定位 API 文档中的某个特定方法或函数方面非常有效，甚至可能比网站本身更好。

在本书结束时，您将掌握源自十年数据工程经验的技能、知识和实践。许多供应商和云计算服务提供商在您首次注册时会提供免费额度。我鼓励您利用这些免费额度，探索各种工具和服务，并获取知识。完成后，请记得清理您的工作空间，关闭所有虚拟机和数据库，备份您的工作，并删除云中的工作空间，以防止产生额外费用。
