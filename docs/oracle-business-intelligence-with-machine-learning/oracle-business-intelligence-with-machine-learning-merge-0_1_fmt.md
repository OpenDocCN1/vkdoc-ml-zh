# 1. 引言

“我思故我在。”正如这一概念在哲学课堂上引发了关于人类存在的讨论，如今它同样适用于探索“作为一个思考实体”的真正含义。此外，它还引发了当今关于人工智能（AI）的讨论，探讨其与人类智能的关系及对比。人工智能的目标是创造一种模仿或复制人类思维过程的物体吗？如果是这样，那么西方哲学家笛卡尔的这句名言，在存在、思考能力，以及——或许同样重要，尤其是在机器学习中——怀疑能力，或解读某事物具有不确定性或模糊性的能力方面，便具有了全新的意义。

超越哲学范畴，这个看似简单的概念如今可以应用于我们在分析和机器学习方面的能力。但它无疑引出了一个非常直接的问题：我们真的能模仿人类思考的方式吗？或者至少，机器能像人类一样得出逻辑吗？如果能，那么它是否就属于思考实体？再者，我们真的需要进行这种比较吗？还是说，我们只是在寻找任何方法来复制或影响由思考或决策所产生的结果？

事实上，智能与分析行业正在经历剧变。新技术以及随之而来的新工具，催生了新的能力。环顾四周，机器学习已经以显而易见的方式得到应用。它是面部识别、文本转语音识别、收件箱垃圾邮件过滤器、在线购物、可查看推荐、信用卡欺诈检测等众多技术背后的支撑。研究人员正在将统计学和计算机科学相结合，构建能够以更少计算资源、更高效解决更复杂问题的算法。从医疗诊断到社交媒体，机器学习改变世界的潜力确实令人难以置信——而且它已经到来！

这一切的核心便是机器学习，它试图模仿人类学习事物的过程。作为人类，我们是如何拥有通过经验来学习并提升任务能力的能力的？当我们出生时，几乎一无所知，也无法自理。但很快，我们每天都在学习和变得更强大。计算机真的能做到同样的事吗？我们能否制造一台机器，并对其进行编程，使其像人类一样思考和学习？如果能，这意味着什么？本书将探讨这种能力，以及如何将其有效应用于商业智能和分析领域。你将看到机器学习如何通过人工智能技术获得的可操作知识和洞察，来改变组织的决策过程。

> **注意**
> 本书的主要焦点是将人工智能（机器学习）应用于商业世界的实际场景。仅仅陶醉于技术本身是不够的。相反，我们感兴趣的是它如何为了组织的利益而改变流程和功能。在商业智能方面，这显然指向了获得竞争优势的能力。

鉴于人工智能和机器学习预计将在我们的日常生活中普及，你可能想对它们有所了解。让我们从几个定义开始介绍我们的主题（[`www.oracle.com/technetwork/issue-archive/2016/16-jul/o46ai-3076576.html`](http://www.oracle.com/technetwork/issue-archive/2016/16-jul/o46ai-3076576.html)）：

*   **人工智能**：机器无需针对特定任务进行专门编程即可执行该任务的能力。人工智能现在与机器人技术以及机器执行类人任务（如图像识别和自然语言处理）的能力密切相关。
*   **机器学习**：一种或一组算法，使计算机能够识别数据集中的模式，并以可操作的方式解释这些模式。
*   **监督学习**：一种机器学习模型，其在特定参数范围内对数据集进行解释。垃圾邮件过滤器就是一个常见的例子。
*   **无监督学习**：一种机器学习模型，在执行解释时涵盖整个数据集。数据挖掘就使用这种技术。
*   **预测分析**：一种机器学习模型，通过解释数据集中的模式来预测未来结果。注意：并非所有预测分析系统都使用机器学习或基于人工智能的技术。

## 人工智能与机器学习

据说，西方世界的伟大思想家亚里士多德一直在寻找一种方法来表征人类推理和思考的方式。2000 年后，《数学原理》的出版为数学奠定了基础。随后，这项工作使得艾伦·图灵在 1942 年证明，任何形式的数学推理都可以通过使用 1 和 0 的机器来处理。这反过来又引发了一些关于机器对人类影响的哲学思考。

严重依赖早期哲学家的理论，人工智能的发展在上世纪后半叶加速，因为商业界对以实际方式应用人工智能产生了兴趣。[1] 这一演进的核心是计算能力的进步，以及通过数据库和商业智能（以及现在的大数据）有效处理数据的能力的提升。随着每一项技术的进步，我们都离能够充分利用人工智能更近一步。

> **注意**
> 基于早期哲学和逻辑设计的系统之所以失败，主要是因为缺乏计算能力、难以获取大量数据，以及无法描述不确定性和模糊性。[1]

让我们将人工智能宽泛地定义为“研究合成和分析能够智能行动的计算代理的领域”。[2] 从这个角度来看，我们的重点是具有智能行动能力的计算代理。就我们的讨论而言，我们无需关注那些执行人工智能的、迷人的类人机器人——这通常是人们关注的焦点。我们只需同意，所有人工智能的目标都是构建具有目标的、智能且自主的代理。

在这个人工智能的背景下，我们将关注代理需要完成什么目标。主要而言，人工智能旨在自主运行，以得出最佳预期结果。在本书的背景下，这个预期结果是改进决策并辅助预测分析。

那么，代理如何变得智能并成功实现其目标呢？答案在于表征和推理。

在构建人工智能系统时，你必须做到以下几点：

*   获取并表征关于某个领域的知识（表征）
*   利用这些知识解决该领域中的问题（推理）

代理可以通过过去行动和观察的经验，来形成对当前环境的表征。这些数据及其他数据为其制定推理提供了输入。作为设计解决问题程序的一部分，我们必须定义知识将如何被代理表征和存储。然后，我们必须确定目标，以及什么算作该目标的解决方案。换句话说，我们希望做到以下几点：

*   用计算机能够理解的语言来表征问题（表征）
*   对计算机进行编程以计算输出（使用知识和推理）
*   将输出转化为问题的解决方案

人工智能的学习方面决定了知识是被给定的还是被习得的。如果知识是被习得的，那么我们就进入了人工智能的一个子类别，称为机器学习。[2]

### 机器学习概述

机器学习融合了计算机科学与统计学等多个学科。简单来说，人工智能处理的是从数据中提取特征并形成统计信息，以解决预测任务的问题。而机器学习则采用了一种独特的方法来实现这一目标。它致力于设计一种机器学习智能体，使其能够在没有明确、简洁指令的情况下进行预测。

本质上，机器学习通过尝试寻找一个能够预测结果的函数，让计算机得以“学习”。因此，机器学习的核心在于对所提供的数据进行探索和发掘。这正是它在数据驱动的企业业务中大显身手之处：在海量数据中搜索并发现特定的结构或统计模式。通过这种方式，机器学习使我们能够处理那些过去难以解决或我们根本不知道如何解决的数据问题。在过去，即使是数据本身的庞大体量，也给处理和提取关键信息带来了困难。后续章节将详细阐述机器学习如何通过企业商业智能（BI）和高级分析解决方案，在组织中得到应用和实施。

简单来说，机器学习使计算机（机器）能够从特定的任务和从数据中发现的模式中学习。而且，它无需被编程设定执行该任务所需的具体步骤——这很像人类能够解读和分析经验以改进任务。换句话说，计算机学习的是如何最好地执行任务，而不是被编程设定完成任务的特定步骤和指令。至少可以说，这非同寻常，因为机器正在模仿人类的学习能力。让我们更进一步，应用这个概念。

为了解决众多任务并提供正确的输出，机器学习从输入中提取特征，以期被引导至期望的目标点。想象一下，一个幼儿通过观察花朵独特的结构来识别它；输入到幼儿大脑中的是视觉感知到的光子，并由大脑进行处理。但幼儿并非生来就知道花是花。他是通过反复看到花朵，并识别出诸如茎、花瓣和圆形对称等独特特征来学会的。机器学习人工智能与此类似，它通过经验来学习和改进执行任务（例如识别花朵）的能力。

这里的关键在于，识别的算法并非由设计者或程序员专门指定。相反，它是通过重复的数据和统计方法创造出来的。机器学习的人工智能体需要被训练。作为训练的一部分，必须提供大量的历史数据。[5]

随着机器学习的应用日益普及，将会出现一些在分析中既高效又易于使用的算法。一个简单但高效的算法例子是，它能找到一条最优直线，根据给定的类别对数据进行分离和分类。在这种情况下，类别可以根据你的特征和特性来指定。随着计算机输入越来越多的图像，它可以开始检查该特征是否属于你已学习的属性。甚至在此之前，它就可以扫描一张图片，判断图片中的物体是否是人。机器学习算法可以从这里开始，或许还能识别出照片中的人。它学习判断图像是否是人。一条虚拟的线被确定下来，用以指示该物体是否确实是人类。也许机器会进一步专门寻找人脸或面部特征。

### 模式，模式，还是模式

机器学习一个至关重要且重要的分支是模式识别。数据中的模式和规律有助于形成有意义的标签。这种模式识别模仿了我们人类在观察事物时对其进行分类和归类的过程。随着时间的推移和重复强化，我们开始识别观察中的模式，从而开始从这些模式中学习的过程。在当今大数据的世界里，机器的工作方式与此非常相似；随着计算机筛选海量数据来学习和识别模式，这种重复现在可以以加速的方式轻松实现。

以在社交媒体应用中区分人脸为例。该应用被输入图像，并开始基于数据点构建信息。一台被编程为学习的计算机会在数据中寻找统计模式，使其能够识别并随后表示这些信息，在空间中以数字方式组织它们。但至关重要的是，是计算机，而不是程序员，识别出这些模式并建立算法，未来的数据将据此进行分类。当然，也可能会出错。计算机接收的数据越多，其算法就越精细，预测也就越准确。应用于“识别”人脸时，会确定一些决定性的点来区分和识别相似之处。

但如果数据点模糊不清，不那么确定呢？机器能否区分一个人的肖像甚至是一个人的表征（例如，在一幅画中）？

这个问题的答案可能包含了区分人类推理和机器学习的本质，并让我们得以一窥，如果我们具备了推理能力，未来可能会是什么样子。一个人可以通过运用对猫王面部特征（即使在这里有些模糊）以及他紧闭双眼、对着麦克风深情演唱时可能的样子，来识别出一幅抽象画中猫王的某种相似之处。通过过去的经验和观察，我们学习并知道猫王有某种特定的姿态，因此我们应用、推理并接受这确实是他的一个表征。另一方面，如果没有这种推理能力，并且依赖于确定的数据点，机器可能根本无法将画中的图像与猫王熟悉的面孔关联起来，如下所示：

我们可以推断，这种相似度足以让我们对这幅画做出有根据的猜测，而机器则无法捕捉到这种模式来学习和识别其相似之处。然后，我们就可以开始理解机器究竟是如何学习的，以及模式识别是如何成为这种能力的关键。

机器学习主要可以分为三种类型。其中两大类是监督学习和无监督学习。它们对于当今的大数据最为适用和贴切。

在无监督学习中，智能体能够从提供的输入中识别出模式。此外，没有明确的反馈或指令给出。最常见的无监督学习任务是**聚类**，它涉及检测输入示例中可能有用的簇。[1] 让我们将这个概念应用到人类身上。儿童不需要被告知某物是花，就能将其识别为一种独特的东西；当反复看到时，花就会在儿童的大脑中作为视觉模式被记录下来。在没有具体指导的情况下，儿童能够识别出花是属于某一类的事物。与“花”这个词的关联是后来建立的，它只是对儿童大脑中已经归类的这个事物进行的一个分类。只要有足够覆盖所有可能性的数据，就可以进行分组。聚类是最常见的分组类型。

将此与**监督学习**进行对比，在监督学习中，智能体在尝试相应地澄清和分类项目时，会获得直接的输入作为聚焦点。

此外，除了监督/无监督学习，我们还有**强化学习**。在这里，智能体（以监督或无监督的方式）从一系列以奖励或惩罚形式出现的强化信号中学习。二元结果是重点，因为每个相应的奖励或惩罚分别向机器表明它可能做对了或做错了什么。然后由智能体决定在强化信号之前采取的哪些行动对其结果影响最大。[1] 反过来，机器利用这些信息进一步学习，并朝着某个特定结果前进。

这只是机器学习所涵盖方法中的一小部分示例。在后续章节中，我们将讨论甚至将这些方法应用于实际案例。然而，我们并不试图在这本书中完整解释机器学习；我们只关注主要主题，如知识发现和分类。不过，我们将在我们的博客 [`www.bis3.com`](http://www.bis3.com) 上继续讨论这个主题，在那里我们介绍商业智能软件、服务和解决方案的最新信息。

### Oracle BI 与大数据

自助服务，更重要的是由此产生的可操作分析，可以成为现实，因为最新的技术和业务分析流程（例如移动设备管理、可视化发现和电子表格分析）变得由业务用户驱动，并且所有必要的数据点之间没有脱节。Oracle 对企业的专注使这成为可能。

OBIEE 与 Oracle Essbase 相结合，提供了一个整体解决方案，能够对结构化数据进行预测分析、运营 BI 和自助式报告。同样，Oracle 提供的分析和大数据产品可以帮助将 BI 扩展到关系数据及其多维分析之外，从而允许对海量数据进行自助式分析。这可以回答我们所说的关于大数据的谁、什么、何时、为什么，甚至如何的问题，并且几乎实时地，通过仪表盘和各种数据可视化方式轻松呈现结果，以揭示发现的关键信息。

后续章节将探讨 Oracle 的数据可视化和数据准备工具、技术以及人工智能组件的进步，如何改变我们在当今高级分析世界中处理和利用数据的方式。

### 适用于 Oracle BI 的 R 语言

当今分析领域最大的推动者和变革者，或许就是将用于统计的 R 语言引入各种商业智能和分析产品。从 2012 年开始，Oracle 在人工智能领域迈出了一大步，当时它宣布推出用于大数据的 Oracle 高级分析。该软件包将 R 统计编程语言集成到 Oracle 数据库（当时为 11g 版本）中，并将 Oracle R Enterprise 与 Oracle Data Mining 捆绑在一起。自那时起，Oracle 持续在其 BI 工具套件中添加 R 语言及其功能。Oracle 还致力于将其用于机器学习，以微调和改进自身产品，包括其旗舰数据库产品，该产品被称为自愈数据库系统。

R 语言于 1995 年作为开源项目推出，已被数百万用户用于统计分析。Oracle 已将其集成，并使其功能能够被其应用程序和系统利用。Oracle 客户可以利用这种分析功能，从其 Oracle 系统中收集的所有数据中探索和发现有价值的信息。

本书稍后将提供一个应用 R 语言和机器学习技术来创建和开发可操作 BI 和分析的示例。

## 总结

本章介绍了人工智能和机器学习——从它们早期的历史和演变，到当今世界成为我们日常生活中的变革者。大量算法以及成功使用机器学习技术的应用程序已经被编写出来。从农业和制造业等行业中早期的任务自动化开始，我们现在已经进入了一个为知识工作者寻求新应用以实现任务自动化的时代。

其中一个自动化领域是决策支持系统（DSS）和企业数据仓库（EDW），尤其是在组织内部。正是在这里，计算能力和处理海量数据的能力正通过人工智能驱动技术的新应用接受考验。EDW 的基本目标是在已集成和存储的数据中发现趋势。通常，只有在 EDW 中，组织才能拥有完全收集、集成并进一步清洗的数据；这使得能够提供一套可用的数据，从而提供对企业的历史洞察并揭示趋势。应用人工智能和机器学习可以通过提供缺失或未知的数据来进一步扩展 EDW。

能够发现趋势和基本模式的机器学习应用算法，恰好符合 EDW 的精确焦点和目的。OBIEE 是面向未来企业商业和商业世界的完美人工智能驱动技术。

借助 Oracle 的 OBIEE 套件，功能现已进入人工智能领域。本书提供了设置 `R` 语言和机器学习的逐步说明。此外，本书还提供了一个案例研究，作为将机器学习应用于商业世界的示例。
