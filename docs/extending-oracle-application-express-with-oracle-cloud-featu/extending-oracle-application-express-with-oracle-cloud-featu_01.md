## 引言

有三个话题是许多人感兴趣的：云解决方案、低代码/无代码开发以及机器学习/人工智能 (AI)。通常，原因是我们都需要用更少的钱，尽可能快地实现更多目标。竞争很激烈，我们需要比竞争对手更有效地利用我们的时间和资源，以便更快地做出正确的决策。我们需要了解业务、数据及其包含的信息。而且，我们不想把工作时间花在基本的维护任务上，因为那会占用处理更重要、更关键的业务工作的时间。而且，非常诚实地说，我们中的许多人从事信息与通信技术 (ICT) 工作，是为了能够每天学习新的、有趣的东西。

在这本书中，我们讨论了所有这三个主题，甚至更多。我们讨论了 Oracle 云基础设施 (OCI) 和 OCI 中可用的 Oracle 自治数据库 (ADB)。ADB 自动包含 Oracle Application Express (APEX) 低代码环境和用于 SQL 和 Python 的 Oracle 机器学习 (OML) 功能。APEX 和 OML 都是数据库预装且免费的功能。

APEX 让您能够以尽可能少的工作和时间构建适用于任何企业的应用程序，包括非常轻松地构建概念验证。但这可能是您已经知道的事情，并且您可能和我们一样对 APEX 感到兴奋。您可能不知道的是，在 OCI 中，ADB 中的 APEX 也由 Oracle 维护：ADB 和 APEX 都由 Oracle 自动修补。OML 和 OCI 的其他机器学习/数据科学功能使得使用现有的机器学习模型和 AI 解决方案或构建新的模型和解决方案变得容易。
