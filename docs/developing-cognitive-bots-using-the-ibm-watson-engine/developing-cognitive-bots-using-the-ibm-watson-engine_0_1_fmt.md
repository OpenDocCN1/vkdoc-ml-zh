# 第 1 章 认知虚拟机器人简介

昨天还是科幻小说的事物，今天正在成为现实。许多技术都是如此，认知虚拟助手就是这样一种应运而生的技术。

几年前，我读过一本书，书中主角创建了一个具有认知能力的自学习聊天程序，能够像任何人类一样做出回应。当时，这看起来只是一个与科幻惊悚片相关的故事情节。然而，直到几年前还只是一个概念的东西，如今由于`认知虚拟助手`（更常被称为`聊天机器人`）的出现，已经大规模成为现实。

`聊天机器人`是一种计算机程序，它通过听觉或文本方式进行自然语言对话，理解用户的意图，并根据业务规则和组织数据发送响应。它的表现方式与人类在双向对话中的表现相同。

从 1950 年艾伦·图灵在《计算机器与智能》(`en.wikipedia.org/wiki/Computing_Machinery_and_Intelligence`) 一文中提出的概念，以及 1966 年第一个名为 Eliza 的`聊天机器人`的诞生，发展到今天，它已经演变成一个由人工智能技术和机器学习算法驱动的、非常复杂的互联生态系统。如今，`聊天机器人`可以帮助用户订披萨、预订假期、购买保险单，或执行像管理企业 IT 基础设施这样非常复杂的任务，以及更多其他功能。

随着以客户为中心的个性化体验的兴起，当今企业必须能够在较短的周转时间内，以更高的个性化程度，并且在客户历史和画像方面零延迟地与其最终用户进行相关对话。根据高德纳公司的数据，到 2020 年，25% 的客户服务运营将使用虚拟客户助手

(`www.gartner.com/en/newsroom/press-releases/2018-02-19-gartner-says-25-percent-of-customer-service-operations-will-use-virtual-customer-assistants-by-2020`)。它进一步预测，虚拟`聊天机器人`有望丰富客户体验，在整个互动过程中帮助客户，并代表客户处理交易。有趣的是，由谷歌、`IBM`、Facebook、微软等公司提供的开源平台推动的技术民主化，使得即使没有专业程序员也能创建`聊天机器人`。

如果这些数据点让你感到兴奋，并且你想探索构建自己的虚拟聊天代理的可能性，那么这本书就是为你准备的。

本书可作为在 `IBM` 开发的 `Watson` 平台上构建`聊天机器人`的指南。我们将为银行、金融、保险、旅游、股票市场等不同用例开发`聊天机器人`。我们还将讨论其他认知平台，如 `LUIS`、`Lex` 和 `Dialogflow`。在本书的后续部分，我们将探索不同的机器人框架，例如 `Microsoft Bot Framework` 和 `Bot Builder`。

让我们更深入地探讨本书的主题：认知虚拟助手。`助手`一词指的是协助执行任务或活动的人或物。`虚拟`一词很容易让人联想到软件以及存在于虚拟世界中的事物。`认知`一词则与人类的认知能力有关。

让我们看看认知是如何被定义的。认知是“通过思考、经验和感官获取知识和理解的心理活动或过程。”它涵盖了智力功能和过程的许多方面，例如注意力、知识的形成、记忆和工作记忆、判断和评估、推理与计算、问题解决与决策、语言的理解与生成。认知过程利用现有知识并产生新知识。

简单来说，认知是人类的一种能力，它帮助我们获取知识、执行所有心智功能、理解我们所处的环境，并创造新知识。

认知型或智能虚拟助手旨在变得更像人类，并具备人类所拥有的类似能力，尽管距离这一目标成为现实，我们仍有很长的路要走。

`CVA`（认知虚拟代理）具备上述部分能力，但在理解我们世界中纷繁复杂的语境方面，它们可能还无法与人类匹敌。然而，在某些领域，它们超越了人类，因为它们没有生物性的处理能力限制，并且能够同时扩展并与数百万用户进行沟通，这是人类无法做到的。

让我们来定义一下认知虚拟助手。`CVA` 是一种软件代理，它基于文本、语音、手势或视觉输入为个人或系统执行任务。它在不同程度上具备理解所提供输入、解释输入、应用逐步逻辑、探询用户意图和对话语境的能力，并据此提供信息或执行预期任务。它能理解自然语言对话，并维持对话的语境以实现目标。

一些 `CVA` 能够通过首先使用语音转文本来解释语音指令，而另一些则能识别图像并据此采取行动。

在回应方面，`CVA` 可以在通信模式为消息系统时使用文本回复，可以通过语音频道使用语音回复，并且可以通过机器人外观展示手势、表情或动作来表达自己。`CVA` 也被嵌入到扬声器和汽车导航系统等设备中。

这些设备中一些支持语音的具体例子有 `Google Home` 和 `Amazon Echo`。

`CVA` 可在多种设备和界面上使用，并且可以通过移动手持设备、笔记本电脑或个人电脑访问。它们也可以通过不同的消息平台访问，例如 `Facebook Messenger`、`Skype`、`Telegram` 等。

`CVA` 被嵌入到大众使用的移动应用程序中，这些应用程序被称为`数字个人助理`。数字个人助理的几个例子包括苹果的 `Siri`、谷歌的 `Google Assistant` 和微软的 `Cortana`。数字个人助理帮助用户完成搜索、导航和通信等任务。数字个人助理需要通过一个命令来激活，以便它们知道用户正在尝试发起对话。这些语音命令的一些例子有“OK Google”、“Alexa”等。

虚拟助手可以被用来提供各种服务。以下是一些例子。

• 充当搜索和检索代理，从各种来源检索结果，例如天气、股票更新、市场信息、价格、目录、利率等。
• 充当配置代理，配置提醒、闹钟、创建待办事项列表、购物清单、旅行行程等。
• 从目录和订阅服务中播放视频或音乐，例如 `Spotify`、`Netflix`、`Amazon Prime` 等。
• 充当 IT 服务台代理，解决 IT 设备的问题和故障。
• 在专业服务中充当助手，例如医疗保健、法律、行政和金融。
• 充当设备（扬声器、电视和其他设备）中的嵌入式代理。
• 充当车辆和汽车中的代理，以辅助导航和操作娱乐设备，例如音乐播放器等。

## 认知虚拟助手的隐私问题

`CVA`（认知虚拟助手）存在明显且实际的安全隐患。一些消费级认知虚拟助手始终处于“监听模式”，等待语音激活关键词。这意味着人与人之间的私密对话会不断被 `CVA` 的麦克风捕捉。这些消费级 `CVA` 公司会录制部分数据，并将其用于训练系统，以更好地识别人类语音和意图。毕竟，在 `CVA` 后台运行的深度学习系统需要海量真实数据来进行训练和优化。

由于 `CVA` 基于音频指令工作，因此有可能通过嵌入人耳无法察觉的音频指令来欺骗或入侵它们——例如将这些指令隐藏在音乐中，或通过电子设备播放的语音文本中。这些手段可被用来操纵 `CVA` 执行黑客控制的动作。与 `CVA` 相关的另一个风险是，黑客可以操纵虚拟助手入侵系统，甚至获得进入住宅和办公室的物理权限。

AI 技术提供了像 `CVA` 这样的能力，但也使得模仿和重建某人的声纹变得更加容易。如今，已有技术可以创建某人带有精确声纹的伪造视频；这项技术正日益精进。

这些担忧在近期已成为新闻头条。`CVA` 的制造商已经发布了使用建议，让用户能够更好地控制自己的数据是否被存储，以及是否被提供商使用。作为这些系统的消费者，我们应当充分了解私人数据泄露的风险。我们应当知晓如何根据自身的隐私需求来使用系统。

# 认知虚拟助手：技术、生态与用例

## 概述与厂商工具

• IBM Watson 是一套人工智能产品。它提供对话、翻译等 API，以及一个名为 `Watson Assistant` 的开箱即用解决方案，用于快速创建和配置认知虚拟助手。

• Amazon Lex 和 Polly 是亚马逊云服务（AWS）提供的工具，用于快速创建和配置认知虚拟助手。AWS 还提供其他服务，帮助用户增强 CVA 的功能。

• Google 提供 `Dialogflow` 供开发者创建引人入胜的虚拟代理。它还提供其他服务，包括语言翻译和语音识别，以增强认知虚拟助手的基本功能。

## `Bot` vs. 认知虚拟助手

当今技术领域存在多种术语；其中最流行的是聊天机器人、虚拟代理、虚拟助手和机器人。尽管这些术语听起来相似，但它们在功能和特性上存在重大差异。让我们来理解这些术语。

• `Bot` 是 `robot`（机器人）的简称。它指代任何在互联网上运行的自动化程序。你可能听说过诸如 `Twitter 机器人` 和 `聊天机器人` 之类的术语。它们是提供特定类型功能的机器人或软件机器人的具体实例。

聊天机器人是一种特定类型的软件机器人，用于对用户查询或任何其他类型的对话提供自动回复。

• 虚拟助手是一种特定类型的机器人，它执行助手的职能，协助用户完成其意图执行的功能；例如，设置闹钟、管理日历、阅读邮件、播放歌曲等。

• 聊天机器人和虚拟助手都可以是脚本化的，或者具备人工智能特性。当它们只是简单的脚本，并且不使用自然语言理解（`NLU`）时，它们不被视为认知聊天机器人或认知虚拟助手。

以下是认知聊天机器人或认知虚拟代理的特性和功能。

• 自然语言理解能力，这意味着机器人具备理解查询或对话意图的智能。

• 从模型中学习的机器学习能力；基本输入包括多个聊天对话、词典和语料库。

• 从错误中学习并增强对对话上下文和意图理解的能力。

• 与其他基于 AI 的服务（如拼写检查器、语言翻译和语气分析器）集成的能力。与普通的聊天机器人或助手相比，这些额外的 AI 服务使认知聊天机器人或助手变得非常强大。

• 进行更类人对话的能力，因为上述所有特性使得认知代理在对话中比普通机器人更接近人类。

• 自然语言生成（`NLG`）能力；这些机器人能够根据与聊天机器人对话的用户个性来生成对话回复。

另一个显著差异在于维护对话流程方面。在与聊天机器人交互时，如果你中断对话，机器人将无法记住交互的上下文。另一方面，虚拟助手利用动态对话流技术来理解人类意图，从而丰富与人类的对话。

## 对企业与生态系统的影响

传统上，企业使用网站和网络应用程序作为提供信息和收集客户信息的手段。想想当今的任何企业服务，你会发现它都有一个网站和各种可供授权用户使用的应用程序。用户体验是当今任何数字企业的信条，它们一直在大力投资，通过利用各种技术创新来改善用户体验。在当今世界，数字企业有两个目标。一是通过缩短周期时间和降低成本来提高效率，二是增强用户体验。认知虚拟助手正成为同时满足这两种需求的关键技术。

认知助手正在提供改进的用户体验，同时带来更高的安全性、更简单的业务流程，并减少人类代理的单调工作，使他们能够接受培训以解决更复杂的问题。认知虚拟代理正成为第一道防线，而当 `CVA` 无法回答最终用户的问题或解决问题时，人类代理则成为后备力量。

越来越多的网站现在将虚拟助手作为面向客户的交互界面，客户可以在其中寻求信息、提供输入、搜索网站上的特定内容、获取导航帮助、填写表格、请求服务和更新。其中一些由认知技术驱动，而另一些则是简单的脚本化机器人。认知助手正在被迅速采用，大多数大型组织已经实施或正在实施认知虚拟助手技术。

## 认知虚拟助手的用例

### `IT` 服务的自助服务/服务台

利用认知虚拟助手实现 IT 服务的自助服务是一个用例，它具有巨大潜力来减少 IT 服务台团队的工作量。在竞争异常激烈的环境中，大多数组织的优先事项是降低提供 IT 服务的成本，同时确保用户获得最佳服务。

由于 `CVA` 可以全天候在线，并且能够同时处理数百个同时进行的对话中，IT 服务台里人们等待响应的任何高峰都被消除了。借助 `CVA` 提供的自助服务功能，用户可以解决大部分与笔记本电脑、台式机、电子邮件、`Microsoft Office` 套件或其他企业应用相关的查询或问题。

像密码重置或访问应用程序帮助这样简单但通常量很大的用例，可以轻松由 `CVA` 完成，从而腾出 IT 资源的时间，去帮助用户解决更复杂的问题。

由于 IT 贯穿各个垂直行业，这里创建的用例可以跨多个行业垂直领域复用。许多垂直行业（包括银行与金融服务、旅游、医疗保健、酒店和零售）已经在为 IT 服务台用例部署 `CVA` 的道路上。

一些机器人捆绑了 IT 服务台用例，以便更快地采用并实现即用型消费。其中一个这样的机器人框架是 `DRYiCE Lucy`，它为 IT 提供了数百个开箱即用的用例（[www.dryice.ai/](http://www.dryice.ai/)）。

### 分类

分类类别下有许多用例。一些 IT 服务台用例也属于分类范畴。一个分类 `CVA` 可以询问和探究用户面临的问题，然后将其引导或分类到正确的信息或正确的人工客服那里去解决问题。

为了更好地理解分类用例，可以将其视为一个智能 `IVR`。`IVR` 要求用户在电话网络中选择一个选项，并根据所选选项提供信息或转接给人工客服。电信公司、宽带公司或银行的 `IVR` 系统是分类如何工作的一个很好的例子。

组织可以利用 `CVA` 的能力将 `IVR` 转变为智能通信，从而提升用户体验。

智能 `CVA` 可以解读用户想要什么，并且比 `IVR` 更快地提供正确的信息。由于 `CVA` 可以与企业应用集成，像查询账户余额或证券余额这样的信息，用 `CVA` 实现起来很容易。

### 线索生成

线索生成，曾被认为是一项需要人类完成大部分任务的活动，正在迅速实现自动化。

线索生成 `CVA` 大多嵌入在网站中。当你进入组织网站的任何页面时，会弹出一个 `CVA` 弹窗，并与访问者开始对话。

使用 `CVA` 作为网站上的线索生成前端正在迅速普及，如今，大多数网站都有 `CVA` 协助访问者获取信息。

`CVA` 在网站上的好处是，访问者可以快速直观地获取信息，无需浏览整个网站并逐页导航来获取所需信息。

在这种情况下，由于访问者正在与 `CVA` 交互，用户不再是被动的访问者，而是活跃的访问者，他们通过聊天对话提供信息，这些信息随后可用作线索、反馈等。

### 电子商务

电子商务虚拟助手正在帮助数百万消费者通过直观的界面浏览、选择和购买产品和服务。

由于电子商务网站上列出了数百万种产品，用户越来越难以搜索和找到他们想要购买的商品和服务。`CVA` 具有利用机器学习技术进行对话和快速搜索信息的广泛能力，这使得在线买卖变得更加容易。

电子商务 `CVA` 具有扩展功能和能力，包括匹配买家和卖家的算法。

有了 `CVA`，整个交易变得自然且双向，这与静态且没有对话流程的网站形成对比。

想象一个场景，你在询问一个产品，`CVA` 可以精确定位并向你展示你想要的 exact 产品。在一个静态的网站上，如果价格不符合你的预期，你可能不会购买该产品。然而，`CVA` 可能会查找其他优惠，并根据智能算法为你提供更好的价格。这极大地提升了用户体验。

### 与企业应用集成

我们大多数人都熟悉集成到智能手机或音箱中的流行虚拟助手，例如苹果的 `Siri` 和亚马逊的 `Echo (Alexa)`。在企业方面，我们看到领先的 SaaS 公司正在将流行的消息机器人（如 `Facebook Messenger`）集成到他们的应用程序中。

主要的 ERP 提供商，如 `SAP` 和 `Oracle`，也在为其应用程序开发虚拟助手。该领域的一些聊天机器人示例包括 `Salesforce` 的 `Einstein Bot`。

### 任务跟踪与项目管理

任务管理、提醒和报告是项目中的典型活动。

认知虚拟助手可以查找信息、整理信息并与企业项目管理系统集成，这使得它们非常适合简化和自动化项目管理流程。

用户可以使用 `CVA` 来设置提醒、请求项目状态、安排会议以及搜索项目相关文档。具有机器学习能力的 `CVA` 可以轻松完成所有这些任务。

如今，项目跨越多个地理位置和时区，与多个团队的协调对项目经理来说可能是一个挑战。借助使用 `CVA` 提供的自动化，曾经复杂的事情现在变得简单了。

`CVA` 与大多数企业项目管理工具集成，以自动化流程，并为项目经理、协调员和团队成员提供直观、易于使用的用户界面。

`CVA` 可能还不足以智能到可以规划项目或做出决策，但在不久的将来，这些复杂的任务很可能在 AI 驱动的 `CVA` 的能力范围之内。

### 人力资源

从招聘到员工生命周期的整个人力资源流程，如今都已相当标准化。大多数企业使用 ERP 产品自动化了这些流程。

`CVA` 在人力资源流程中非常契合。招聘、日常员工互动、问题解答、评估周期等都可以通过认知虚拟助手完全自动化。

`CVA` 处理候选人筛选、安排面试、确保面试进行、收集面试反馈、协助填写所需信息表格等任务。

`CVA` 也用于员工加入组织后的入职流程。这项任务需要 `CVA` 引导员工了解各种政策和程序。

大多数新员工都有疑问，他们依赖同事或伙伴来获取这些信息。部署了 `CVA` 后，任务变得更快，并消除了依赖性。这带来了更快的入职速度和更好的员工体验。在日常工作中，与流程、政策、政策变更、休假、差旅、薪酬、福利、保险以及人力资源相关领域的查询，都可以由 `CVA` 准确且以更短的周转时间进行解答。
