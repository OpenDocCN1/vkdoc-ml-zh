# 第 8 章 **认知虚拟助手的未来**



已有企业成功部署了认知虚拟助手（CVA），并切实感受到了其在成本节约、用户体验提升、标准化、简化流程及数字化转型方面带来的益处。

这些组织已能够从竞争中脱颖而出，并在客户服务、净推荐值、客户满意度评分等方面树立了更高标准。通过提供直观的信息与数据访问方式，它们为用户带来了更优质的体验，从而赋能用户更好地服务其终端客户。借助面向合作伙伴、供应商生态系统及其他利益相关方的 CVA，企业间的交互变得更加简洁高效。这加速了信息传播，消除了因多渠道沟通和层层传递造成的时间浪费。

实现认知虚拟助手的价值取决于组织所采取的策略。有些组织构建了由自然语言处理引擎和单一机器人组成的中央生态系统，该机器人由所有部门和职能机构共同使用，其驱动方式更具战略意义而非战术性。由于标准化、更快的学习和采纳速度、部门间的经验共享以及用例与数据的复用，这种方法为组织带来了最大化的收益。同时，这也为客户、合作伙伴和员工提供了统一的交互界面，并配备了相应的用例和功能。

**认知虚拟助手的未来**

CVA 的快速普及预示着未来的发展趋势。一方面，企业正在为部署 CVA 寻找更新、更复杂的用例；另一方面，自然语言、语音识别、图像识别、文本提取和语言翻译等领域的技术正日新月异地进步。

就 CVA 在互联网规模的消费端应用而言，我们已经看到其功能在快速提升。CVA 能够模仿语言、语调和声音，并在特定用例中与人类进行如此精妙的对话，以至于人们很难分辨出另一端是 CVA 在交谈，而非真人。

目前，最先进的 CVA 包括来自谷歌、亚马逊、苹果和微软的个人助手。这些个人助手当前的挑战在于，它们本质上是问答系统，提供基于上下文的完整对话体验的能力有限；尽管谷歌推出了 Duplex，并在少数用例中展示了完全类人对话的能力。

首先，未来的 CVA 将不仅能理解单一意图，还能理解整个对话的上下文，包括偏离主要意图的部分。我们人类在对话时并非直截了当或可预测的，因此，机器要解读接下来可能出现的对话内容颇具挑战性。

大量人工智能研究由初创公司引领，其中一些公司被收购，以便通过科技巨头的资金支持快速扩展技术。AlphaGo 的创造者 DeepMind 于 2014 年 1 月被谷歌以 5 亿美元收购。此后，DeepMind 的技术被应用于谷歌助手。Siri 于 2010 年被苹果收购，如今为 iPhone 中的虚拟助手提供支持。Facebook 于 2015 年收购了 Wit.ai，其技术被用于 Facebook Messenger。微软则收购了 Maluuba，以获取其在对话领域的人工智能技术。


试图模仿人脑工作方式的新技术，将使认知虚拟代理在对话中更具人性化。

我们还需要认知虚拟代理理解对话背后的语气和情绪。语言是复杂的；同一句话在不同的语境或以不同的语气说出，可能具有完全不同的含义。个人认知虚拟助手每天从全球范围内与它们互动的人类那里接收海量数据，这使得我们能够向前迈进，创造出不仅能理解意图和语境，还能理解对话背后情感的认知虚拟代理。

除了个人虚拟代理之外，设备和汽车中的认知虚拟代理也正在蓬勃发展。汽车是一个有趣的用例，因为车载认知伴侣会以不引人注目的方式照顾驾驶员和乘客。它可以连接所有车辆传感器发送的数据，并充当语音助手，提醒驾驶员并提供导航。这种模式不同于自动驾驶模式——后者只是将你从一个地方带到另一个地方。认知虚拟代理可以在自动化模式下工作，帮助乘客选择音乐、调节温度、规划最佳路线以及处理旅途中的其他事务。

诸如“紧急情况下自动拨回家”或“呼叫救护车”等功能将成为认知虚拟代理的常见特性。在发生事故或紧急情况时，它将提供完整的信息。在紧急情况下，关于驾驶员和乘客的个人信息，例如血型和病史，个人助手可以随时获取，从而帮助挽救生命。

在企业中，认知虚拟代理将很快成为员工从面试、入职到完成工作、提交和评估所需的唯一应用程序。从招聘到退休的整个员工生命周期，都将由集成了后端企业资源计划和人力资源系统的强大数字助手来处理。像 DRYiCE Lucy 这样的员工服务机器人正在为企业提供这些功能，并不断扩展其用例和覆盖范围。

凭借这些能力以及认知虚拟代理所能完成的用例的迅速扩展，诸如订票、解决问题、提供餐饮、管理订单、回复邮件查询、解决 IT 问题等低层次任务将被认知虚拟代理接管。对话将更加人性化，以至于很难（如果不是不可能的话）区分人类代理和认知虚拟代理。

认知虚拟代理将能够模仿人类行为，如同理心和理解力，但我们必须意识到，这仅仅是一种模仿，而非与人类等同，因为人类受情感驱动，而认知虚拟代理则使用逻辑来理解和回应情感。

在服务行业，人类经过培训，当客户感到沮丧或愤怒时，能够识别情绪并以特定方式回应——这并非真实的情绪，而是一种让客户感到满意的脚本化回应。然而，基于对话经验，人类服务助理产生偏见的可能性远高于认知虚拟代理。

同样真实的是，此类创新将引发人们对认知虚拟代理对人类工作及其未来影响的担忧。然而，你也可以考虑一种相反的观点：人类已经将其他人变成了机器。随着技术的进步，我们正试图重拾人性，让生活更美好、更丰富，并将人类从那些单调、重复且无需太多智力的任务中解放出来。

这些工作之所以没有更早实现自动化，是因为解决这些问题所需的技术和硬件创新既复杂又难以规模化，尽管与制造汽车的装配线相比，这些任务本身更为简单。

超越语音识别和理解人类对话背后情感的下一个前沿领域是手势。这不仅需要技术进步来识别手势，而且本质上这将是一种重新添加到人类交流模式中的新沟通模式。人类将不得不学习手势，就像他们学习用书写和打字而非说话来交流一样。这将是一场双向的进化：人类使用手势，而认知虚拟代理学习理解这些手势的含义。

完全有可能的是，这个阶段会被完全跳过，我们直接进入一个技术发展到能够理解和解读我们思想的模式——这样我们就不需要用手势来交流了。如果这种情况发生，认知虚拟代理的下一个进步将是读取我们的思想并据此采取行动。这项技术进步的影响将席卷全球。这将是又一个从科幻幻想变为现实的例子；但这确实是一个令人惊叹的进步。

认知虚拟代理将不再局限于问答系统或辅助人类实现其愿望的系统；认知虚拟代理技术的下一次演进将是其理解指令的能力与为用户提供最佳选择的能力的融合。这将是人类不仅下达指令，而且倾听认知虚拟代理建议的第一步。

这类系统的例子已经存在。像谷歌地图这样引导人类而非仅仅接受指令的技术，或者向用户推荐购买物品的推荐系统，或者帮助用户在线比较和购买商品的价格比较引擎，如今都已存在。

在需要从各种来源协作和整理数据的应用和场景中，认知虚拟代理的角色将加速发展和扩大。让我们通过一个简单的例子来理解这一点。为大量人员安排日程、组织会议以及预订会议室是耗时的工作，需要访问日历信息、会议室预订系统和其他应用程序。这类任务可以很容易地由认知虚拟代理自动化完成，因为它可以访问所有系统，并在几秒钟内处理数据。而人类完成这项工作则需要多次点击并与多个应用程序交互。在需要访问信息和规则库的重复性单调任务中，认知虚拟代理远比人类高效。所有企业都拥有一个用于预订会议的认知虚拟代理的未来并不遥远。它还将跟踪人员的空闲情况、会议室以确认会议、发送提醒，或建议适合所有与会者的备选会议时段。

如今，你可能会在新闻文章中看到关于“通用人工智能”和“奇点”不可避免的末日预言——届时人类将创造出能够不断自我重构并实现超级智能的人工智能。当这成为现实时会发生什么，只有它真正发生时才会显现。

但如果我们审视当前的人工智能应用，世界已经转向了“特定人工智能”，这意味着机器执行一项特定任务并完成得很好，有时甚至超越人类能力。如果我们看看 OpenAI 和 DeepMind 创建的人工智能系统，它们能够在经过训练的游戏上击败地球上最优秀的人类。借助深度学习，训练系统正变得越来越简单，尽管计算量和数据量很大。如果我们进行推断并审视认知虚拟助手的技术创新，我们会看到同样的趋势——能够出色地完成有限任务的特定助手的出现。

认知虚拟代理的未来应该更加互联互通。企业和个人计算领域中不同的专业化机器人将协同工作，提供简单直观的体验。

个人机器人将配备适配器或连接器，用于连接

各种机器人，并附带一种机制，用于决定哪个特定意图或主题应交给哪个机器人来解决。目前，机器人之间的通信尚无标准化，但在未来，完全有可能创建并标准化一个通用的机器人框架以及机器人之间数据交换的机制。这将有助于解决多个机器人带来的问题，并加快该领域的创新步伐，许多个人和初创公司将针对特定任务创建机器人。

一个全球性机器人——一个能够看到所有对话、交易和互动的通用互联蜂巢思维——的存在将带来积极和消极的后果；积极的一面在于它能够连接两个环境。第一个是我们所居住的地球的物理环境，第二个则包括我们在数字环境中以流程、系统、数据等形式创建的对象。这样的生态系统将有可能通过自动完成交易、设置提醒、协调人与人、流程与流程、人与流程、人与机器、机器与机器之间的协作，来简化并改变地球上每个人的生活。个人机器人将通过这个通用 API 与其他机器人对话，并完成人类通过与他人交谈、发送电子邮件和会面所做的事情。

机器人将处理我们在家庭和

工作场所中的许多日常琐事。它们将逐步发展到能够独立评估情况，并通过提供主动建议而非被动响应来解决问题。机器人能够与庞大的后端数据库和机器学习引擎集成，这将导致机器人通过更快的数据处理和访问更大、更好的数据库，从而对环境有更深入的了解。认知虚拟助手（CVA）的角色将从被动地提供建议，演变为代表人类做出决策。这将是人类与机器角色互换的转折点。

另一方面，通用机器人将了解每个人的一切。

想象一下，通用机器人拥有改变人们偏好、改变我们思维方式、试图缓慢但坚定地改变我们社会和政治观点的力量——通过向我们提供最符合其自身需求而非我们需求的信息。想象一下，存储在通用机器人中的数据所拥有的力量；它能在全球范围内了解人们的情绪和意图，并且可能不会用它来推进特定议程，或操纵经济和政治体系，但或许会永远改变人类。
