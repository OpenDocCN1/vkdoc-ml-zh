# 2. 入门说明

在本章中，我们将学习 Python 对象和运算符，以及如何在代码中编写注释。在代码中包含注释非常重要，原因有二。首先，它们可以帮助我们在创建脚本数周或数月后，回忆起当时的工作思路。其次，它们有助于其他程序员理解我们为何要这样做。

## Python 中的对象

在 Python 中，任何条目都被视为一个对象，即存放数据的容器。Python 对象包括元组、列表、集合、字典和容器。Python 的处理过程基于对象。

每个对象通过三个属性来区分：

1.  名称

2.  类型

3.  ID

对象名称由字母数字字符和下划线组成——换句话说，即所有 A 到 Z、a 到 z、0 到 9 的字符以及下划线 `_`。“类型”是指对象的类型，例如字符串、数值或布尔值。“ID”是唯一标识该对象的数字。

对象驻留在计算机内存中，并且可以被检索。当不再需要时，垃圾回收功能会释放其占用的空间。

某些 ID 和类型是自动分配的。然而，关于名称，请注意有些名称不能用于对象。

## 系统保留字

Python 有一组为系统保留的单词，不能用作对象或函数的名称。这些单词如下：

> `and`, `as`, `assert`, `break`, `class`, `continue`, `def`, `del`, `elif`, `else`, `except`, `exec`, `False`, `finally`, `for`, `from`, `global`, `if`, `import`, `in`, `is`, `lambda`, `None`, `not`, `or`, `pass`, `print`, `raise`, `return`, `True`, `try`, `while`, `with`, `yield`

此外，R 语言中的对象名称需遵循一些规则：

*   必须以字母或下划线开头。

*   只能包含字母、数字和下划线。

*   区分大小写。例如，`test` 对象与 `TEST` 对象或 `Test` 对象不同。

## 在代码中输入注释

在 Python 中，任何以 `#` 符号开头的注释都不会被程序作为代码读取；它们会被忽略。此功能对于注释代码和日后回忆非常有用。注释可以写在代码行内，也可以写在代码旁边。

```
# 注释 1
>>> print("Hello World") # 注释 2
```

要编写多行注释，我们也可以使用三个引号，如下所示：

```
"""
注释行 1
注释行 2
注释行 3
"""
```

## 运算符

Python 包含一系列运算符，它们被分为几组：

*   算术运算符

*   比较运算符

*   成员运算符

*   位运算符

*   赋值运算符

*   逻辑运算符

*   身份运算符

除了这些运算符之外，还有一个优先级层次结构，标志着它们的使用顺序。运算符对于算术运算，甚至对于提取具有特定特征的数据都非常重要。

### 算术运算符

当我们打开 Python 时，能做的最简单的事情就是用它来执行数学运算，为此我们使用表 2-2 中所示的算术运算符。

**表 2-2 算术运算符**

| 运算符 | 描述 | 示例 |
| --- | --- | --- |
| `+` | 加法 | `3 + 2 = 5` |
| `−` | 减法 | `10 − 4 = 6` |
| `*` | 乘法 | `4 * 3 = 12` |
| `/` | 除法 | `20/2 = 10` |
| `%` | 取模 | `21/2 = 1` |
| `**` | 幂运算 | `3 ** 2 = 9` |
| `//` | 整除 | `10.5 // 2 = 5.0` |

让我们打开 Python 并执行一些数学运算：

```
>>> 10+7

>>> 15-2

>>> 2*3

>>> 10/2

>>> 3**3

>>> 10/3

>>> 25//7
```

### 比较运算符与成员运算符

在 Python 中，我们还有比较运算符和成员运算符（表 2-3）。

**表 2-3 比较运算符与成员运算符**

| 运算符 | 描述 |
| --- | --- |
| `>` | 大于 |
| `<` | 小于 |
| `==` | 等于 |
| `>=` | 大于或等于 |
| `<=` | 小于或等于 |
| `!=` | 不等于 |
| `is` | 是 |
| `is not` | 不是 |
| `in` | 存在于 |
| `not in` | 不存在于 |

这些运算符用于测试对象之间的关系。例如：

```
# 我们创建两个对象
>>> x = 5
>>> y = 10
# 让我们验证 x 是否大于 y
>>> x > y
False
# 输出是一个逻辑向量，告诉我们 x 不大于 y
# 让我们看看 x 是否小于 y
>>> x < y
True
# 让我们创建另一个对象
>>> z = 5
# 让我们用相等运算符验证 z 是否等于 x
>>> z == x
True
# 在这种情况下，输出是肯定的
# 让我们验证 z 是否不等于 y
>>> z != y
True
# 在这种情况下，输出也是肯定的
# 让我们创建一个元组
>>> v1 = (1,2,3,4,5,6,7)
# 并验证数字 2 是否在元组中
>>> 2 in v1
True
# 让我们验证数字 8 是否不在元组 v1 中
>>> 8 not in v1
True
# 让我们验证数字 7 是否不在元组 v1 中
>>> 7 not in v1
False
```

Python 会按字典顺序比较文本字符串，例如使用字符的 ASCII 值。我们不能比较字符串和数字，因为会引发错误。

### 位运算符

表 2-4 中所示的位运算符在指定多个条件时非常有用。例如，当我们需要从对象（如数据集）中提取数据时。

**表 2-4 位运算符**

| 运算符 | 描述 |

### 赋值运算符

赋值运算符用于为给定对象分配一个名称（表 2-5）。

**表 2-5 赋值运算符**

| 运算符 | 描述 | 示例 |
| --- | --- | --- |
| `=` | 基本赋值运算符 | `x = 5 + 6` |
| `+=` | 加后赋值 | `x += y` (对应 `x = x + y`) |
| `-=` | 减后赋值 | `x -= y` (对应 `x = x – y`) |
| `/=` | 除后赋值 | `x /= y` (对应 `x = x/y`) |
| `*=` | 乘后赋值 | `x *= y` (对应 `x = x * y`) |
| `%=` | 取模后赋值 | `x %= y` (对应 `x = x % y`) |
| `**=` | 幂运算后赋值 | `x **= y` (对应 `x = x ** y`) |
| `//=` | 整除后赋值 | `x//=y` (对应 `x = x//y`) |

让我们看一些例子：

# 我们创建一个值为 10 的 x 对象
```python
>>> x = 10
# 对 x 求和并用相同名称覆盖变量 x
>>> x = x + 5
>>> x

# 让我们试试 "+="
>>> x += 5
>>> x

# 现在试试 "-="
>>> x -= 5
>>> x

# 现在使用运算符 "*="
>>> x *= 3
>>> x

# 以及运算符 "/="
>>> x /= 3
>>> x

# 然后是运算符 "**="
>>> x **= 2
>>> x

# 最后是运算符 "//="
>>> x //= 2
>>> x
```

每次，Python 都会执行操作并将结果记录在 `x` 对象中。

## 运算符优先级

谈到数学运算符时，我们必须意识到存在一个优先级顺序，当没有插入括号时必须遵守。这类似于数学运算，其中乘法优先于加法。表 2-6 列出了一些管理运算顺序的优先级规则。

**表 2-6：运算符优先级规则**

| 运算符 | 优先级（从高到低） |
| --- | --- |
| `**` | 幂运算具有最高优先级 |
| `-` | 负号 |
| `*` `/` `//` `%` | 乘法、除法、取模、整除 |
| `+` `-` | 加法和减法 |
| `>>` `<<` | 按位右移和左移 |
| `&` | 按位与 |
| `^` `|` | 按位或 |
| `<=` `>` `<` `>=` | 小于、大于、小于、大于 |
| `==` `!=` | 等于、不等于 |
| `=` `+=` `-=` `*=` `/=` `%=` `**=` `//=` | 赋值运算符 |
| `is` `is not` | 比较 |
| `in` `not in` | 比较 |
| `not` `or` `and` | 比较 |

## 引号

在 Python 中，引号主要用于定义字符串。它们可以是单引号、双引号或三引号。三引号用于包裹文字并在多行中插入注释。例如，当我们希望在正在创建的函数中包含文档时。

```python
>>> ex1 = '单引号'
>>> ex2 = "双引号"
>>> ex3 = """
文本字符串 1
文本字符串 2
文本字符串 3
"""
```
