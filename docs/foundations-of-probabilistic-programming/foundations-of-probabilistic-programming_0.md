

## 关于本电子书

ePUB 是一种开放、行业标准的电子书格式。然而，不同阅读设备和应用程序对 ePUB 及其众多功能的支持程度各不相同。您可以使用设备或应用程序的设置来自定义呈现方式，以满足您的喜好。通常可以自定义的设置包括字体、字号、单栏或双栏显示、横屏或竖屏模式，以及可点击或点击放大的图片。有关您阅读设备或应用程序的设置和功能的更多信息，请访问设备制造商的网站。

许多书籍包含编程代码或配置示例。为了优化这些元素的呈现，请在单栏、横屏模式下查看电子书，并将字体大小调整为最小设置。除了在可重排文本格式中呈现代码和配置外，我们还包含了模仿印刷书籍呈现方式的代码图片；因此，在可重排格式可能影响代码列表呈现的地方，您会看到一个“点击此处查看代码图片”的链接。点击该链接即可查看与印刷版一致的代码图片。要返回之前查看的页面，请点击设备或应用程序上的“返回”按钮。
