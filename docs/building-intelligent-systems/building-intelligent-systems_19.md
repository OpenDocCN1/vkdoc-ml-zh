# 第四部分
创造智能

创造智能

第[16](https://doi.org/10.1007/978-1-4842-3366-5_16)章至第[21](https://doi.org/10.1007/978-1-4842-3366-5_21)章探讨了创造智能的方法。本部分将解释智能可能来自的所有地方（包括机器学习），以及每种方法的优缺点。它将探讨在智能系统生命周期的不同阶段创造智能的目标。它将提供关于如何在团队环境中组织和控制智能创造的见解。

本部分不会详细教授特定的机器学习技术，但会解释支持机器学习技术（以及其他智能创造技术）的关键概念和要素，使团队在开发大型、复杂的智能系统时能够取得成功。
