# 1. 引言

工业化机器学习（IML）正在演变为我们周围世界中的一股颠覆性力量，人们终于认识到它已经并将继续对我们的未来产生的真正影响。在本书中，我将分享我从十多年咨询工作中获得的见解和知识，包括组建三个数据科学团队，为全球商业和研究实践设计和实施数字化转型。

IML 技术和算法的使用在速度、规模和影响力上逐渐积累。仅在过去三年中，其影响就已演变为许多主要业务流程的巨大颠覆者。没有哪个行业不受机器学习日常影响，IML 增长模式的预测显示其规模增长超过 300%，复杂性增长 250%。

在本书中，我将提供一系列广泛的见解和建议，涵盖我在当前咨询生态系统中发现的最有用的方法论和技术。这些将帮助您通过机器学习领域实现能力的工业化。

要将机器学习应用于一组数据集，您需要遵循以下通用流程清单：

*   数据中必须存在可区分的模式。确定数据中的模式是机器学习的主要目标。没有模式，该过程就无法工作。

*   模式不能通过数学公式解决。调查数据模式是否与数学计算直接相关始终是一个好主意。如果存在经过验证的数学公式，您就不需要机器学习；只需在每次需要结果时执行数学计算即可。

*   您必须能够访问数据集的各个方面以学习见解。执行见解所需的数据必须作为“真正的”单一来源可用。遗憾的是，我观察到许多项目执行了重要的机器学习解决方案，却发现他们使用的数据并非针对感兴趣的领域，并且由于限制而不允许使用。请花时间验证您纳入源数据的所有数据源的谱系和来源。

目前机器学习的主流观点是，人类需要保护自己免受其滥用。有多个活跃的阵营在积极控制自主机器的影响。

请注意这些正在发挥作用的力量，因为它们将对您未来可能使用的 IML 技术和算法的水平与性质产生重大影响。

最著名的概念之一是艾萨克·阿西莫夫的“机器人四定律”（艾萨克·阿西莫夫在 1942 年的短篇小说《转圈圈》中起草了这些定律）：

*   第一定律：机器人不得伤害人类，或因不作为而让人类受到伤害。
*   第二定律：机器人必须服从人类给予的命令，除非这些命令与第一定律冲突。
*   第三定律：机器人必须保护自身存在，前提是这种保护不与第一或第二定律冲突。
*   第零定律：机器人不得伤害人类整体，或因不作为而让人类整体受到伤害。

这四条基本法则可以作为数小时深度哲学讨论的基础。我将在后续章节中再次探讨这些法则，以及由新兴的机器伦理学和工业化机器学习领域所引发的元伦理问题。我个人的建议是：能够实现，不代表就应该实施！始终遵循“无害”原则！简而言之：在机器学习中，始终以负责任的态度，为所有相关方带来更优的整体结果。

在讨论机器学习的实施及其在第 14 章中众多法律限制下的后果之前，我将首先介绍基础的机器学习理论。

接下来，我将讨论各种方法论和技巧的基本背景信息。之后，我会提供示例，展示如何在日常生活中部署和使用 IML。

本书的目标读者设定为中级到高级水平。所分享的信息基于以下假设：

*   你具备对 Python 编程生态系统的实际理解。

*   你具备机器学习所需的数学、科学和统计计算的实际知识。
*   你已经掌握基本的机器学习概念，并理解基本技巧。
*   你需要能够从 GitHub 站点获取示例代码。

在具备上述用户经验的前提下，我将以非初学者的节奏，讨论这些技术和算法的基本知识。如果你对每章中涉及的更高级概念不太确定，我建议你查阅附录 A 中的补充材料作为背景知识。
