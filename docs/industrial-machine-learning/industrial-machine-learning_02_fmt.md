## 数据科学

1960 年，彼得·诺尔开始使用“数据科学”一词作为计算机科学的替代术语。他指出，处理数据需要的不仅仅是计算机科学。我同意他的观点。

数据科学是一门跨学科科学，它整合了从异构模式（结构化、半结构化或非结构化）数据中提取知识和洞察的实践与方法。它融合了来自多个发人深省的研究领域的数据探索科学领域，如数据工程、信息科学、计算机科学、统计学、人工智能、机器学习、数据挖掘和预测分析。

当我通过翻译多个数据湖来热情研究数据科学的未来应用时，我发现了一些有价值的见解。我将通过端到端的示例进行解释，并分享我对数据湖的见解。本书解释了这些科学中的关键要素，你可以利用它们将数据湖处理成可操作的知识。我将引导你完成一系列公认的针对数据湖的科学流程。当你开始运用数据科学时，掌握这些核心技能是一套关键资产。

## 数据分析

数据分析是对原始数据进行事实调查分析的科学，其目标是从数据湖中得出结论。它由经过认证的算法驱动，以统计方式定义数据之间的关联，从而产生洞察。

当你需要说服其他业务人员相信你所发现的数据洞察的重要性时，对经过认证的算法的认知尤为重要。

如果有人经常要求你证实这些洞察并解释你如何知道其正确性，你不应感到惊讶！

最好的答案是能够指出你所使用的经过认证且公认的算法。将该算法与你的业务术语相关联，以成功完成你的项目。

## 机器学习

商业世界正因机器学习及其在众多商业环境中的应用而充满活动和想法。机器学习是系统无需明确提供规则就能学习的能力，而软件开发是否属于机器学习的一部分取决于所使用的工具/技术。它源于模式识别和计算学习理论的研究。

其影响在于，通过适当的处理能力和技能，你可以增强自身的数据处理能力。训练使得处理环境能够在你喝杯咖啡的功夫完成多个数量级的发现。

更聪明地工作……而不是更辛苦地工作！将你的数据科学工作卸载给机器；它们在处理上更快、更一致。

这项技能是实现大幅缩短数据到知识周期的关键部分，本书将涵盖基本的实用规则。

## 数据挖掘

数据挖掘是处理数据以隔离模式并建立数据湖内数据实体之间关系的过程。在后续章节中，我将详细阐述如何挖掘数据以获取洞察，这将帮助你发现新的可操作知识。但首先，在你能成功进行数据挖掘之前，你需要了解一些关于数据模式的关键数据挖掘理论。

### 统计学

统计学是研究数据的收集、分析、解释、呈现和组织的学科。统计学涉及数据的各个方面，包括通过调查和实验设计来规划数据收集。

数据科学与统计学密切相关。我将展示如何运用诸如数据收集、总体和样本等统计模型来提升你的数据科学交付成果。本书将在后续章节详细阐述如何将这些要素整合成一个高效且有效的流程。

### 算法

算法是一组自包含、逐步执行的过程，旨在实现特定结果。算法执行计算、数据处理或自动化推理任务，并能产生可重复的结果。

算法是数据科学流程的支柱。你需要整合一系列方法和程序，以简化特定数据湖的复杂性和处理过程。在本书中，我将讨论大量算法以及执行实用数据科学的最佳实践。

### 数据可视化

数据可视化是你与业务方沟通的关键渠道。它包括创建和研究业务洞察的可视化呈现。数据科学的主要交付成果就是可视化。你需要将高度技术性的结果转化为能够向非数据科学人员展示的格式。

从数据结果成功转化为可操作知识是一项技能，我将在后续章节中详细阐述。如果你掌握了可视化技能，就能在数据科学领域取得巨大成功。

### 数据叙事

数据叙事是将数据分析转化为通俗语言的过程，旨在影响业务决策或行动。即使拥有最优秀的数据科学成果，如果没有能够将发现转化为业务相关行动的商业故事，你也不会成功。我将提供详细的实用见解，说明需要检查哪些方面，以确保你同时拥有故事和行动方案。
