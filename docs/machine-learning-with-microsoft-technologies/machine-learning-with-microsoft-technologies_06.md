# 第二部分 使用 R 和 Power BI 进行机器学习

使用 R 和 Power BI 进行机器学习

如今，各行各业对机器学习的应用兴趣浓厚。将 Power BI 视为一个协作式自助服务工具，它支持描述性分析（数据摄取、转换、建模和可视化）的整个价值链。除了这些功能外，Power BI 还提供了用于执行高级分析和机器学习的出色工具。第 5 章至第 8 章主要关注 Power BI 内部的主要机器学习周期。在第 5 章中，将讨论与我们将通过机器学习解决哪些业务问题相关的概念。第 6 章重点介绍在 Power BI 内部进行数据整理（数据清洗）的可能性。第 7 章和第 8 章重点介绍用于预测性和描述性分析的机器学习算法。
