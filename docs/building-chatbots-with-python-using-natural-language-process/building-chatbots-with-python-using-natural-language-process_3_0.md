**如何阅读本书？**  
请记住，本书的写作方式与其他书籍不同。本书的编写理念是：当你读完本书后，能够独立构建聊天机器人，或教会他人如何构建。在开始阅读本书前，请务必牢记以下几点：  
• 本书涵盖构建聊天机器人所需的大部分内容，而非泛泛而谈现有技术。  
• 本书鼓励你花更多时间在系统上动手实践，让本书成为你的得力助手。请务必执行每个代码片段并尝试编写代码，不要直接复制粘贴。  
• 请严格按照书中步骤操作；如果遇到不理解的内容不必担心，后续章节会为你解答。  
• 使用本书附带的源代码和 Jupyter Notebook 作为参考。  

**你将学到什么？**  
**第 1 章：备受喜爱的聊天机器人**  
本章将从商业和开发者双重视角，带你了解聊天机器人的相关知识。本章将为动手实践聊天机器人概念并将其转化为代码奠定基础。希望读完本章后，你能找到为自己或公司构建聊天机器人的充分理由。  

**第 2 章：聊天机器人的自然语言处理**  
本章将学习在聊天机器人中应用自然语言处理（NLP）时所需的工具和方法。本章不仅教授 NLP 方法，还会结合真实案例，通过代码示例进行演示。同时讨论为何聊天机器人需要特定的 NLP 方法。请注意，NLP 本身就是一项值得掌握的技能。  

**第 3 章：轻松构建聊天机器人**  
本章将学习如何使用 Dialogflow 等工具，以简单优雅的方式构建聊天机器人。如果你是非程序员，一定会喜欢本章，因为它几乎不需要编程技能。  

**第 4 章：硬核构建聊天机器人**  
本章将学习人们真正想要的聊天机器人构建方式。标题虽为“硬核”，但完成前一章后，你会渴望更多内容——本章将教你如何从零内部构建聊天机器人，以及如何使用机器学习算法训练它们。  

**第 5 章：部署你的聊天机器人**  
本章专为你的聊天机器人应用提供最后冲刺。当你经历了轻松与硬核两种构建方式后，一定不想让成果只停留在自己手中。你将学习如何通过 Facebook 和 Slack 向世界展示你的聊天机器人，并最终将其集成到自己的网站上。
