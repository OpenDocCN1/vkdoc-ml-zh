### 第 1 章回顾 – 地理数据简介

第 1 章从地理数据的一般介绍开始，包含了一些定义。其中许多定义在你日常处理空间数据的工作中会很有用，包括：

*   笛卡尔坐标
*   极坐标与度数
*   欧几里得距离与哈弗辛距离

接着，该章介绍了一系列用于 GIS 分析的标准工具，包括 `ArcGIS`、`QGIS` 和其他开源软件。本书使用 `Python` 作为工具，并且有众多令人信服的理由来使用它。如果你想成为 GIS 分析专家，学习其他工具也可能很有用，但我们将在本章稍后部分讨论未来学习路径的选择。

第 1 章接着介绍了多种空间数据存储类型：

*   `Shapefile` 文件
*   `KML` 文件
*   `GeoJSON`
*   图像格式（`TIFF`/`JPEG`/`PNG`）
*   标准格式（`CSV`/`TXT`/`Excel`）

在使用 `Python` 时，我们通常拥有更多的数据类型自由度，因为我们可以编程实现任何需要的处理操作。这在点击按钮式的环境中并不总是可行的。无论如何，能够与你可能遇到的任何数据存储格式进行互操作是非常重要的。

本章最后介绍了一些在 `Python` 中处理空间数据的重要 `Python` 库，其中一些在本书的其他章节中被广泛使用。

### 第 2 章回顾 – 坐标系与投影

在第 2 章中，我们更详细地探讨了坐标系和投影。数据中的空间参考是区分空间数据与非空间数据的要素。坐标系是使空间数据处理变得困难的因素之一。即使你的数据集中有经纬度列，根据坐标系的不同，也有多种解释方式。

在制作地图时，你还会遇到一个理论问题：如何将本质上是 3D 物体的地球部分展示在 2D 图像上。这是不可能的，我们需要从多种投影中选择，每种投影都有其自身的缺陷。通常，地图会尝试在正确面积、正确距离、正确形状和正确方向这四个标准中尊重其中一个。我们需要找到最符合我们需求的那一个。所涉及的坐标和投影系统包括：

*   `WGS 1984` 地理坐标系
*   `ETRS89` 地理坐标系
*   摩尔威德等面积投影（又称 `Babinet` 投影）
*   阿尔伯斯等面积圆锥投影
*   墨卡托等角投影
*   兰勃特等角圆锥投影
*   等距方位投影
*   等距圆锥投影
*   兰勃特等面积方位投影
*   两点等距投影

世界上存在许多坐标系，找到最适合你需求的那个可能是一个挑战。如有疑问，最好坚持使用更常见的投影，而不是更高级的，因为如果你的最终用户对地图感到陌生，他们可能会感到困惑。

### 第 3 章回顾 – 地理数据类型

在第 3 章中，你学习了地理数据可能具有的不同数据类型。第一个重要的区别是矢量数据和栅格数据。栅格数据是类似图像的数据，它将地图表面划分为像素，并为每个像素分配一个值。这通常用于科学计算，如水文学、地球科学等。热力图就是一个很好的例子，因为它没有特定的形状，而是需要指定地图上每个位置的热度。

矢量数据的工作方式则非常不同。在矢量数据中，存在地理参考的对象。有三种主要的矢量数据类型：点、线和面。

*   点数据只有一个坐标。点没有大小和形状，只有位置。
*   线是一系列点的序列。线由每个点到下一个点的直线组成，但整体线可以由许多直线部分构成一个形状。线也有长度，但没有面积，宽度为零。
*   面是任何其他形式，因为它们捕捉了地图之间的一个表面。面由一系列点组成，这些点共同构成了面的边界。边界内的所有区域都是面的一部分。面有边界长度和表面积。

为你的项目选择数据类型将完全取决于你的用例。尽管数据类型之间的转换有时可能不太容易定义，但必要的转换情况确实会发生，通常你可以使用一些 `GIS` 空间工具来完成。

### 第 4 章回顾 – 创建地图

第 4 章深入探讨了如何使用 `Python` 制作地图。由于 `Python` 是一种开源语言，有许多贡献者维护着用于制作地图的库。最终，你可以选择你喜欢的库，但本章涵盖了多种方法。

第一种方法是结合使用 `geopandas` 和 `matplotlib`。`Geopandas` 是一个用于处理地理数据的优秀 `Python` 包，因为它与著名的 `Pandas` 库非常相似，而 `Pandas` 是一个在数据科学领域广泛使用的数据处理库。`Matplotlib` 是一个绘图库，同样在数据科学社区中被广泛使用。因此，对于有数据科学生态系统经验的人来说，这两个库的结合非常受欢迎。

其次，你了解了如何使用 `Cartopy` 库构建地图。虽然对于数据科学家来说，它可能不太直观，但它仍然提供了许多更贴近 `GIS` 和空间分析领域的选项。如果你有空间分析或制图学背景，这种方法可能是一个很好的选择。

`Plotly` 被作为使用 `Python` 进行地图绘制的第三种选择提出。`Plotly` 纯粹是一个数据可视化库，它将地图制作视为“另一种可视化”。对于那些非常看重地图视觉效果的用户来说，`Plotly` 是一个用于制作地图的绝佳工具。

作为第四种地图绘制工具，我们研究了 `Folium`。`Folium` 非常适合制作交互式地图。当你使用 `Folium` 创建地图时，你创建的视觉效果几乎会带有类似谷歌地图的感觉。当然，这无法在报告或 `PowerPoint` 中使用，并且有其特定的应用场景，即数字交付的用例。它也非常适合数据探索。

### 第 5 章回顾 – 裁剪与相交

在第 5 章到第 8 章中，介绍了一些 `GIS` 空间操作。第 5 章从裁剪操作和相交操作开始。

裁剪操作允许你获取一个空间数据集，并剪掉所有位于你为裁剪指定的边界之外的数据部分。这甚至适用于部分位于边界内、部分位于边界外的要素（线、面），并且会对这些形状进行修改。

相交是一种空间叠加操作，它允许你获取两个输入数据集，并且只保留第一个数据集中与第二个数据集中的要素相交的那些要素。与许多其他空间叠加操作一样，此操作源于集合论。

在本章的 `Python` 示例中，你首先了解了如何对包含多个空间要素的数据集应用裁剪。在相交示例中，你了解了如何查找河流与道路的交点，以确定桥梁的位置。当道路与河流相交时，必定有桥梁或隧道。

### 第 6 章回顾 – 缓冲区

第 6 章介绍了缓冲区操作。缓冲区是任何现有空间形状（点、线、面）周围的区域。创建缓冲区在空间操作中很常用，因为它允许你创建一个不仅包含原始要素，还包含其邻近区域的形状。

在本章的 `Python` 用例中，你使用了多个数据集，根据到公园、地铁站等的距离标准，来定义一个你想要购买房屋的区域。你在这里使用了相交操作来找到一个同时满足所有标准的位置。

### 第 7 章回顾 – 合并与融合

第 7 章涵盖了合并操作和融合操作。本章从合并的不同定义开始。空间连接不仅仅是简单地将不同要素放入同一个数据集，它还会基于空间重叠将不同数据集的字段（列）组合在一起。这是一个非常有用的操作，因为我们习惯于只有在两个表之间有共同标识符时才能进行表连接。对于空间数据，这并非必需，因为我们可以使用坐标来识别要素（或要素的部分）是否重叠。

融合工具则不同，它的目的不是进行类似连接的合并。相反，当你希望基于一个特定值将许多要素合并成较少数量的要素时，它非常有用。这就像是一种空间分组操作。

### 第 8 章回顾 – 擦除

关于空间操作的第四部分也是最后一部分是第 8 章，介绍了擦除操作。尽管擦除有不同的定义，但我们介绍了一种空间擦除操作，即你想要擦除空间参考数据集中的特定部分。这不是基于共同标识符完成的，也不是一次性移除整个要素（行），而是通过修改数据，保留那些需要擦除的要素部分，并保留那些需要保留的要素部分。

### 第 9 章回顾 – 插值

从第 9 章开始，我们转向了更多数学主题，尽管插值在空间操作中也是一个非常常见的用例。插值是在没有测量值的区域中填充数值的任务，即使你在邻近区域有测量值。

插值是数学中一个被广泛研究的课题，人们可以根据需要使插值变得非常复杂。本章涵盖的不同插值方法包括：

*   线性插值
*   多项式插值
*   分段多项式插值，也称为样条插值
*   最近邻插值
*   线性普通克里金法
*   高斯普通克里金法
*   指数普通克里金法

在本章的 `Python` 示例中，我们研究了一个基准测试，该测试比较了其中多种方法，并观察它们的结果有何不同。由于在插值中没有真实值，我们需要找到一种方法来确定哪种方法最适合使用。

### 第 10 章回顾 – 分类

在第 10 章和第 11 章中，我们介绍了监督式机器学习家族中的两种主要机器学习方法。监督式机器学习是机器学习的一个分支，旨在通过将模型拟合到目标变量的历史数据以及一些预测变量上，来预测目标值。

在分类中，我们处理的是类别型的目标变量。我们针对分类情况介绍了特定的模型和评估指标。

关于分类的 Python 示例涵盖了一个用例，其中我们使用了购物中心顾客的移动数据，并利用这些数据拟合了一个预测模型，该模型旨在根据一个人的移动模式预测他是否会对某个产品感兴趣。这个示例使用了前面章节中的空间操作来为模型进行数据预处理。

### 第 11 章回顾 – 回归

回归是分类问题的监督式机器学习对应方法。在分类问题中目标变量是类别型，而在回归问题中目标变量是数值型。你已经看到了许多可用于回归场景的评估指标和机器学习模型。

本章的 Python 示例使用了空间数据和非空间数据来预测阿姆斯特丹公寓的 Airbnb 价格。你在此看到了一个示例，展示了如何准备空间数据和非空间数据，最终得到一个适合构建回归模型的数据集。你还了解了如何拟合、评估和比较多个用于回归的机器学习模型。

### 第 12 章回顾 – 聚类

在上一章中，你了解了第三种机器学习方法——聚类。聚类与回归和分类有很大不同，因为聚类中没有目标变量。由于该方法属于无监督模型家族，其目标不是预测某事物，而是基于距离和相似性识别相似的观测组。

对空间数据进行聚类有一些特殊性，因为计算空间数据（坐标）上的距离需要在数学上保持正确。正如你在本书前几章中所见，两个坐标之间的距离不能使用标准的欧几里得距离正确计算。

本章的 Python 用例展示了如何使用 `OPTICS` 聚类模型结合半正矢距离度量，创建一种聚类方法，用于在三个 GPS 追踪人员的运动模式中寻找兴趣点。本章结束了关于空间数据机器学习的部分。

## 进一步学习路径

当然，本书应该已经为你提供了关于 Python 处理空间数据以及空间数据机器学习的扎实入门知识，但总有更多东西需要学习。本节将为你提供一些进一步学习的思路。当然，学习从来不止一条路，所以你可以将此视为启发，而非唯一的前进方式。

由于本书主要涉及空间数据和机器学习，两个有趣的进一步学习方向可能是：专攻 GIS 领域，或者深入机器学习。此外，像空间数据的数据存储和数据工程等内容也可能很有趣，尽管它们与本书内容稍有距离。

### 深入专业 GIS

如果你想成为 GIS 和空间分析领域的专家，我建议学习像 `ArcGIS` 和 `QGIS` 这样的特定工具，或者至少从了解这些工具并掌握其基础操作开始。

在这条路径上，花时间学习空间统计方法至关重要，包括空间自相关、空间异质性、克里金法及其他插值工具，以及更多空间分析的理论。

花更多时间学习地图制作也是值得的，因为这个领域的最终交付成果通常就是地图。制作地图可能很容易，但制作出色的地图需要时间和精力，因为它们最终是用于解读和沟通的工具。掌握这项技能将让你的时间物有所值。

### 专攻机器学习

尽管本书涉及了多种应用于空间数据的机器学习方法，但机器学习本身是一个非常复杂的数学领域。如果你想成为机器学习专家，有很多东西需要学习。

这条职业道路目前非常受欢迎，因为它让许多人能够工作在当今技术的前沿，但必须指出的是，要跟上这个领域的步伐，需要经历一个相当陡峭的学习曲线。

### 遥感与图像处理

本书未涉及遥感，但得益于计算机视觉的最新进展，地球观测和遥感领域也取得了许多进步。如你所知，大量卫星持续环绕地球运行并传回照片。借助人工智能的新技术，这些照片可以由计算机解读，并服务于大量用途。

尽管计算机视觉可能看起来是一个令人生畏且困难的领域，但你可以将其视为掌握“常规”机器学习之后的下一个学习步骤。当然，这里的学习曲线也可能很陡峭，但用例通常非常有趣且处于前沿水平。

### 其他专业方向

还有其他一些研究领域与本书涉及的主题相关。例如，我们广泛讨论了不同的数据存储类型，但没有深入探讨特定的 GIS 数据库和长期存储等内容。如果你对数据工程或数据库感兴趣，那么关于空间数据的特定存储以及与之相关的一切（数据架构、安全性、可访问性等）还有更多内容需要学习。

许多其他领域也有大量 GIS 相关的工作负载。考虑气象学、水文学以及生态学和地球科学的某些领域，在这些领域中，许多专业人士本身就是 GIS 专家，仅仅是因为空间数据在这些领域中的巨大影响。

当你掌握了空间数据操作后，你会惊讶于有多少领域实际上可以从空间操作中受益。有些领域已经意识到了这一点，并在日常工作中大量依赖 GIS，而在其他领域，一切还有待开创。
