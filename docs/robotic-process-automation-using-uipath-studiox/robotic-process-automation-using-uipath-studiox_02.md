# 1. 机器人流程自动化：概述

为了在当今高度自动化的世界中保持竞争力，数字化转型举措已成为各行各业的主要关注点。传统上，企业高管越来越关注降低运营支出，特别是与人力劳动力相关的成本。此外，业务领导者同时致力于在整个企业中提高效率和员工满意度。因此，公司正在对现有业务流程进行更高程度的审视，以在全球范围内寻找自动化的机会。流程优化的一个领域是通常由业务利益相关者执行的桌面级流程。由于业务利益相关者执行的自动化机会比例很高，通常会出现一种自下而上的方法，即员工根据个人需求选择要自动化的任务。他们不仅可以帮助识别自动化的机会，还可以自行创建自动化，以便专注于高价值任务。随着智能自动化，特别是机器人流程自动化（RPA）的出现，公司现在拥有了一种经过验证的方法，可以在按键级别自动化业务流程。

UiPath 提供了一种技术，能够使用称为“机器人”的可配置软件，自动化传统上由业务用户执行的业务流程。UiPath 的开发平台 StudioX 极其灵活且用户友好，因为它是一个低代码/无代码解决方案。该软件允许用户通过机器人来与系统交互，机器人可以使用用户自身的凭据，也可以配置为使用不同的凭据和特定权限。机器人流程自动化工具通过与用户界面（UI）交互以及通过系统后端的方式，与最终用户相同的方式与应用程序交互。

从合规性和风险角度来看，机器人只能执行专门为虚拟机器人工作者设计的任务。机器人对内部和外部系统的访问权限受限于机器人工作流的设计，这体现了该软件的基于规则的性质。机器人还可以设计为提示用户输入，或结合人工智能（AI）来处理更复杂的认知任务。因此，机器人流程自动化能够自动化那些通常是业务用户日常工作职责基本组成部分的手动、重复性任务。

机器人流程自动化软件的一个基本前提是，机器人软件旨在补充人力劳动力，通过赋予组织提升员工技能的能力，让员工构建简单的自动化，或将更复杂的自动化路由到核心自动化团队中的一组开发人员。将机器人流程自动化功能引入业务部门，可以最大化员工产出的效率，最小化人为错误的风险，并减少员工需要执行的繁琐、手动流程的数量，从而提高员工满意度的潜力。

## 投资回报率（ROI）

除了能够自动化重复性任务外，机器人流程自动化软件还可以为业务流程所有者和整个企业提供可观的回报。机器人流程自动化软件允许公司以成本高效的方式自动化手动流程，因为 RPA 软件的价格点通常低于传统业务应用程序。机器人有助于最小化自动化项目中通常产生的成本，因为机器人流程自动化工具可以利用现有基础设施架构，而不会影响实时系统。

与其他工具相比，支持机器人所需的基础设施相当少，因为机器人可以在最终用户的桌面上运行（有人值守自动化），也可以在虚拟机上运行（无人值守自动化）。机器人流程自动化的众多好处之一是，用户能够决定在给定工作流中由人类还是机器人负责执行流程的特定步骤。此外，工作流可以定制，以指示机器人何时遇到每个系统中的变化，包括常规软件升级，其中用户界面的元素可能与先前版本有所不同。机器人流程自动化的一个重要好处是，用户能够创建工作流以支持动态变化的环境，同时对底层基础设施能力的影响最小。


## 自动化类型

接下来，我们将深入探讨无人值守机器人和有人值守机器人的细微差别，以理解这两种自动化类型之间的区别如何推动一种新的方法，即通过公民开发者（具备构建自动化能力的业务用户）来实现业务流程自动化。机器人流程自动化可用于自动化各种流程，包括但不限于薪资处理、客户服务、广告运营、报告汇总和供应商入职。机器人流程自动化还提供了多种自动化部署模型，这些模型可以互换使用，以自动化整个企业中的流程，包括：

*   **有人值守机器人**：驻留在最终用户的计算机或虚拟机上，用于自动化可由用户操作触发的简单手动流程。

*   **无人值守机器人**：可配置为驻留在本地（基于物理服务器）或非本地（基于虚拟机/云）的机器上，用于自动化更复杂的后台功能，这些功能通常按时间或队列进行调度。通常，无人值守自动化适用于数据密集型任务和交易量较高的流程，例如批处理作业。

*   **混合机器人**：结合了最终用户解决方案与本地/非本地解决方案，能够实现有人值守和无人值守两种处理方式的结合，从而对需要人工支持和后端功能的流程进行端到端自动化。

每种自动化部署模型都允许最终用户根据手头的任务，并仔细考虑每个环境中的现有变量，来确定与机器人交互的最佳方式。各种自动化部署模型可以作为整体企业级自动化平台和数字化转型战略的一部分互换使用。接下来，我们将重点介绍机器人流程自动化行业领导者 UiPath 的特定功能和动手练习，以讨论该公司通过使用 StudioX 为公民开发者提供的独特价值主张。

## UiPath StudioX

UiPath 是一家全球性的机器人流程自动化软件公司，总部位于罗马尼亚。该公司由 Daniel Dines 于 2005 年创立。公司最初提供自动化库和软件作为外包服务，但很快通过以客户为中心的模式将自己定位为行业领导者，该模式旨在普及机器人流程自动化功能的访问。通过强大的产品路线图和独特的方法，使业务用户能够通过 StudioX 自动化简单的业务流程，UiPath 的企业平台展示了业务流程与自动化能力之间的无缝融合。

StudioX 是 UiPath 机器人流程自动化平台的一个产品，旨在使业务用户无需传统的开发背景即可构建自动化。StudioX 功能包括一个无代码界面，具有开箱即用的拖放功能，以方便使用。此外，StudioX 还包含预设计的模板以及与常见业务应用程序（如 Microsoft Office 套件）的原生集成，以加快自动化工作流的开发。业务用户可以直接将机器人部署到本地机器（例如桌面），从而消除了对传统 IT 部署支持的需求。此外，StudioX 框架中还内置了治理功能，允许审计能力，以确保现有的公司合规协议保持不变。关于自动化的调度和共享，用户可以通过 UiPath 的 UiPath Assistant 和 Orchestrator 组件完成这两项任务。

展示 StudioX 灵活性的关键要素之一是，该工具为业务用户提供了一种用户友好的方式来学习如何构建对其工作职能有益的自动化，同时学习一项新的技术技能。在一个技术能力日益重要的世界里，为员工提供利用机器人流程自动化工具的机会可以帮助个人感到更有能力和更满意，从而可能降低人员流失率。公民开发者模式是一种方法论，通过这种方法，业务用户接受构建自动化所需技能的培训，同时获得 RPA 工具的访问权限，以开始开发机器人工作流。随着机器人流程自动化在众多行业中持续扩展，继续通过诸如 StudioX 之类的工具扩展业务用户的知识，以在组织层面提供丰富的益处，将变得非常重要。
